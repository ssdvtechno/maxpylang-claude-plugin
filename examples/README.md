# Examples

Built by the plugin during testing. Regenerate with MaxPyLang installed:

```bash
cd examples && python3 build_arpeggiator.py && python3 build_chorus.py
```

- `arpeggiator.maxpat`: drunk walk over a minor pentatonic scale with random octave jumps and an echo.
  Click the `ezdac~`, then the toggle.
- `chorus.amxd`: Max for Live stereo chorus (Rate, Depth, Mix). Drop on an audio track in Live.
